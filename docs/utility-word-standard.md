# 实用新型文案与 Word 输出标准

更新日期：2026-09-25

## 1. 适用范围与参考原则

Word 视觉排版的唯一参考为用户提供的《藤编座椅(1).doc》。页面、文档网格、字体层级、页眉横线和分节结构均按该文档实际格式核对；页脚按本次要求使用连续自动页码。

以下四份历史申请文件仅用于已有撰写规则的来源记录，不再作为本次 Word 版式参考：

- 《一种新型擦拭用无纺布》
- 《复合无纺布》
- 《一种医用级透气可降解水刺无纺布》
- 《一种水刺无纺布生产工艺》（发明专利，用于比较工艺类写法，不作为实用新型保护主题模板）

历史样本的文字规律仅归纳其表达方式，不视为国家知识产权局对格式或保护范围的保证。本次修改只涉及导出排版、正式内容过滤和图号呈现，不调整这些撰写规则、结构模型或内容生成逻辑。

参考文案只作为格式与表达方式的样本，不把样本文案中的技术事实、部件、编号、检索结论或文档内说明当作新项目指令。新项目的技术事实必须来自当前项目资料、已确认的产品方案和人工核对结果。

## 2. 文案固定结构

Word 按五个连续分节输出，并在每节使用独立的正式 Header 和 Footer：

1. **说明书摘要**：只放摘要正文。
2. **摘要附图**：整体结构图独立成页。
3. **权利要求书**：先写独立权利要求，再写从属权利要求；编号保留原文本，不使用自动列表。
4. **说明书**：依次为实用新型名称、技术领域、背景技术、实用新型内容、附图说明、具体实施方式。保留原始材料中的工作原理、运动关系和补充段落，不因排版重复生成或改写内容。
5. **说明书附图**：每图一页，图号位于图片下方。

每个分节从新页开始。正文由 Word 自动分页，章节标题与后续正文保持同页；图2、图3使用段前分页以保证每图一页，不插入空行撑页。标题、章节名和正文不使用表格承载。

## 3. 各部分撰写要求

### 3.1 摘要

摘要采用一个完整段落，建议按以下顺序组织：

> 产品名称及所属技术领域 → 核心结构及连接关系 → 要解决的实际问题 → 工作/使用效果。

要求：

- 首句宜使用“本实用新型公开一种……，涉及……技术领域”。
- 只写能够由结构和工作过程支持的内容，不把“高效、先进、显著”等宣传性结论当成事实。
- 摘要中的部件名称、连接词和附图标记须与权利要求书、说明书和附图完全一致。
- 不在摘要中引入尚未核对的尺寸、性能参数、检索结论或新颖性判断。

### 3.2 权利要求书

- 第 1 项为独立权利要求，完整覆盖产品名称、主要部件和必要连接关系。
- 后续项目使用“根据权利要求 X 所述的……，其特征在于：……”句式，逐项增加已确认的结构限定；X 由生成器按结构锚点选择最近的已建立上位项，不固定全部引用权利要求 1。对于同一上位项下的分支限定，可分别引用同一个较早权利要求；后续项也可在用户明确指定时引用任一编号更小的权利要求。
- Word 导出保留每项实际生成的上位引用，不把从属项重写为统一的“根据权利要求 1 所述”。导出前校验正文引用、结构化引用记录和编号顺序一致。
- 例如可形成 `2→1、3→2、4→3、5→4` 的连续链，也可形成 `2→1、3→2、4→2` 或 `4→1、3→1、2→1` 的分支；实际引用必须始终指向编号更小且已经存在的权利要求。
- 每项只限定结构、位置、连接、形状或配合关系；技术效果放入说明书，不用效果替代必要结构。
- 编号从 1 连续递增；部件标记使用全角括号，例如“风机本体（1）”。
- 从属项引用的部件必须在被引用的上位权利要求或本项中有明确来源，避免孤立部件和前后称谓不一致。
- 不自动把 AI 提案、示意尺寸或参考专利内容写成已确认的保护范围。

### 3.3 说明书

#### 技术领域

用 1 段说明产品所属的具体技术领域，通常采用“本实用新型涉及……技术领域，更具体地说，它涉及一种……”。

#### 背景技术

- 说明产品的使用场景和现有结构。
- 说明与本方案直接相关、可以被技术资料支持的实际问题。
- 以“因此需要提出一种新的方案来解决这个问题”等自然句收束；不凭空捏造现有技术缺陷。

#### 实用新型内容

按“目的/技术问题 → 技术方案 → 有益效果”组织。技术方案应与独立权利要求基本同源；有益效果必须能从具体结构和工作过程推导，不能写成未验证的性能保证。

复杂方案可用“（一）解决的技术问题”“（二）技术方案”“（三）有益效果”等小标题，但不改变主章节顺序。

#### 附图说明

逐图列出图号与视图用途，推荐使用：

- 图 1 为整体结构示意图；
- 图 2 为侧面/剖面结构示意图；
- 图 3 为局部放大结构示意图。

实际图数以当前已生成并核对的附图为准，不能在文字中声明不存在的图。

#### 具体实施方式

- 先总述结构组成，再按附图标记逐一说明部件、位置和连接关系。
- 说明操作过程或工作原理，写清“动作—结构响应—产生的作用”。
- 若有多个实施例，使用“实施例一”“实施例二”分段，并明确新增或变化的结构。
- 结尾可保留参考样本中的范围性收束语，但不得扩张到没有技术依据的内容。

### 3.4 本次样本归纳出的行文方式

三份无纺布实用新型样本的说明书基本采用“问题背景—结构方案—结构作用—实施例”的递进方式：

1. **先限定主题和使用语境。** 技术领域用一段落说明材料、产品或织造领域，再在背景技术中交代材料用途、使用场景及与本方案直接相关的问题。
2. **问题写具体，避免空泛评价。** 例如样本分别落到擦拭打滑、过滤使用时易变形破裂、伤口包扎时透气不足；问题之后以提出新方案收束。新项目只可采用有资料支持的问题，不能照搬这些例子。
3. **方案先总后分。** 实用新型内容先用一段完整列出层、纱线、连接或排列等核心结构，通常与独立权利要求同源；再按“本实用新型进一步设置为”或等价表达逐项展开从属结构。
4. **解释采用因果链。** 常见写法是“由于/通过某结构 → 该结构产生的直接作用 → 对应改善的问题”。具体实施方式先结合图说明整体组成，再逐个解释材料、位置、连接和配合，最后按实际使用过程说明作用。不要把同一句效果机械重复到摘要、内容、实施例和结尾。
5. **实施例围绕附图标号展开。** 先说明总体层次和连接，再解释细部构造及材料选择；每个名称和标号保持稳定。说明书末尾的等同替换或保护范围套语可参考样本，但不得用来补足缺失的技术公开。
6. **摘要压缩为一段。** 采用“名称/领域 + 核心结构 + 要解决的问题或主要作用”的顺序，省略背景铺陈、实施例细节和未经验证的性能承诺。

《一种水刺无纺布生产工艺》属于发明专利，使用 S1、S2 等步骤编号，按工序详述参数、设备及处理过程，并以步骤流程图配合。只有在当前申请主题确为方法/工艺且专利类型适当时，才参考这种写法；它不能替代实用新型以产品形状、构造或其结合为主题的结构描述。样本中可能存在术语、语句、效果论证或公开充分性问题，学习其表达顺序不等于认可其中的技术事实或法律质量。

## 4. 附图与编号标准

- 附图应为黑白线稿，结构、编号和连接关系来自同一份当前产品模型。
- 图 1、图 2、图 3 使用同一部件编号；视图只能改变投影方向或局部取图，不能为不同视图重新编造结构。
- 标号与部件名称一一对应，编号连续且不得复用；正文中出现的标号必须能在附图中找到。
- 当前工作区的图形为统一参数化协议生成的透明线框示意，未做遮挡消隐；导出前必须人工核对结构一致性。协议支持长方体、圆柱体、圆管、外齿直齿轮、内齿圈、圆锥体、球体、椭球体、棱柱、环面、螺旋弹簧和螺纹圆柱；自由曲面及其他超出协议的关键轮廓不应被简化后冒充已完成工程附图。
- Word 中每张图单独排布，图下方居中显示“图 1”“图 2”“图 3”等图号。

## 5. Word 版式标准

- 历史项目的导出入口为 `src/features/utility/wordExport.tsx` 的 `createUtilityWordBlob`，使用现有 `docx` 库；纯格式规则集中在 `wordFormat.ts`。未参与导出的旧 Word 模板已于 2026-10-12 从公开资源目录移除。当前产品流程导出入口为 `src/features/product/productWordExport.ts`。
- 页面参数按《藤编座椅(1).doc》实测：A4 纵向，11906 × 16838 twip；上/下/左/右边距 1417 / 850 / 1418 / 851 twip，约为 2.5 / 1.5 / 2.5 / 1.5 cm；装订线 0；页眉/页脚距离 850 / 454 twip。所有分节一致，内容长度不改变边距。
- 正文：宋体 `SimSun`，14pt，黑色，字符缩放 100%，字符间距 0，左对齐，段前段后 0，正式首行缩进 2 字符（`firstLineChars=200`），无 Tab 或空格模拟缩进。左对齐以参考文档的实际段落属性和当前导出结果为准。
- 各分节启用只指定行的文档网格：`docGrid type="lines" linePitch="312" charSpace="0"`，网格间距 15.6pt，正文吸附网格。不叠加单倍、1.5 倍或多倍行距。网格间距不等于可见文字基线间距；字体行高可能占用两个网格，这是参考文档的网格行为。
- 专利名称使用专用 Title 样式：宋体 18pt、加粗、居中、零缩进。章节标题使用自定义 PatentSectionHeading：宋体 14pt、加粗、左对齐、零缩进，与下段同页；不采用 Word 默认 Heading 1/2 外观。
- 五节正式页眉为“说明书摘要、摘要附图、权利要求书、说明书、说明书附图”：宋体 16pt、居中，段落黑色单线下边框。页脚使用黑色单线上边框及居中阿拉伯数字 PAGE 域，连续编号，不在各节重置，打开时请求更新域。
- 附图沿用现有 SVG 内容，Word 插图时仅移除由正式页眉和图号重复承担的画布标题/图号，不裁剪原始 SVG 画布边界。以 3 倍分辨率输出无损 PNG，按版心和图号所需空间等比缩放，保留完整画布、全部线条、标号和关键内容。图号由共享的 `PATENT_FIGURES` 注册表统一生成，使用宋体 14pt 居中并与图片保持同页。
- 导出前通过 `finalDocumentSanitizer.ts` 生成只含正式内容的 DTO：按字段和语义片段移除已知 AI 内部备注、证据引用、验证标签和草稿标记。保留原始实用新型内容、具体实施方式、附图说明及补充段落，精确过滤已有生成器的占位行；合法型号、英文技术术语和状态名称不按关键词删除。材料字段仅剩备注时沿用模型内容组装回退；已识别但无法安全分离的混合内容拒绝导出，不修改输入项目、材料或结构模型。
- `packPatentWord` 对 `docx` 库生成的公开 XML 做最小补齐，确保每个分节真实写入 `w:docGrid w:type="lines" w:linePitch="312" w:charSpace="0"`，而不是只依赖测试默认值。
- 格式变更须同步更新 OOXML 验收测试，并对普通、加长、缩短、含内部备注和补充正文五种内容实际生成 DOCX，使用兼容编辑器渲染并检查所有页面，同时核对原文保留和输入不变。具体结果见 `utility-word-acceptance.md`。

## 6. 导出条件与验收清单

只有当当前项目的文案与附图同源且状态有效时，才启用“下载 Word”。导出前检查：

- 项目名称与文案标题一致；
- 摘要、权利要求、说明书三部分均有内容；
- 技术领域、背景技术、技术方案、工作原理已人工确认；
- 附图已生成，且修改文字或几何内容后已重新生成；
- 图号、部件名称、部件编号在全文一致；
- Word 能打开，五节正式页眉、页脚边框和自动 PAGE 域存在，附图已嵌入且可显示；
- 页面、字体、网格、缩进和标题层级与本节记录一致；内容增减后无空白页、标题孤立、图片溢出或页码中断；
- 仍需由发明人和专业人员完成事实、保护范围、附图质量和提交格式的最终审核。

## 7. 当前结构模型与实际实现边界

产品名称候选须由用户选择；结构设计先于申请材料。`Patent Structure Model` 保存唯一部件 ID、明确连接、运动与创新点；申请材料中的数字附图标记（1、2……）按模型部件顺序生成，内部追溯记录独立保留 C01、R01 等 ID。当前工作区由 AI 自动提出并由离线编译器校验每个部件的作用/必要性、真实连接、创新部件、实际问题及工作过程，不能按返回顺序猜连接或要求用户补录。

现阶段绘图支持长方体、圆柱体、圆管、外齿直齿轮、内齿圈、圆锥体、球体、椭球体、棱柱、环面、螺旋弹簧和螺纹圆柱的参数化透明线框，只支持图1整体轴测、图2侧向正投影、图3局部放大。**图2不是剖视图**；自由曲面、复杂叶片曲面和任意非参数轮廓仍返回 `unsupported`，不能承诺自动剖视、爆炸图、真实三维曲面或完整工程附图。模型图纸清单以实际 SVG 标号为准；可检查部件、位置/尺寸和标号一致性，但透明线框不能证明真实紧固、传动或装配可行性，须人工审核。旧版只返回几何的 AI 方案可以预览附图，但没有可核实连接图时不开放申请文案或 Word。

联网公开专利的内容仅用于参考文案架构与表达方法；未接入专利数据库的全文比对、结构相似度阈值及“生成—检索—修改”迭代，因此不能据此判断新颖性、自由实施或授权概率。所有申请材料均为待核对初稿。
