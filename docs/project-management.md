# 项目管理

项目管理采用“企业列表 → 企业专利”的两层结构。右上角“新增企业”弹窗填写公司名称和主营产品，创建或编辑后回到企业列表。主营产品支持用顿号、逗号、分号和换行分隔，自动去重；同名企业不允许重复创建。列表支持按公司名称、主营产品搜索与筛选。

点击企业进入 `#projects/<企业ID>`，只显示属于该公司的专利，支持直接访问、刷新和返回企业列表。企业改名后，专利通过稳定的 `companyId` 保持关联，不重写已生成的技术成果。首次加载时从已有项目的公司和原始产品资料生成企业目录，并补齐关联。

企业支持编辑与确认删除。删除只移除企业资料，原有专利进入“未归属企业的专利”，可在编辑专利时重新指定企业。删除后刷新不会从历史项目重新创建同名企业。“全部专利”保留跨企业查询入口。

企业专利页右上角“新增专利”默认实用新型，自动关联当前公司；仅有一个主营产品时自动带入基础产品名，多个主营产品提供输入建议。填写项目名称、基础产品名称和描述后，点击“选择问题”，在同一弹窗内选择问题并点击“下一步”。项目自动开始生成，仍留在当前企业的专利页，可继续新增或切换企业，任务持续运行。切换知识产权类型不会跳转页面。

项目列表支持按项目名称、生成的专利名称、公司和基础产品名搜索。公司、基础产品名、知识产权类型、材料状态和申报状态可组合筛选。基础产品名保存用户输入的“闸门”“屏幕”等分类，不会被生成名称替换。旧项目优先从原始产品输入恢复分类；没有原始信息的项目可以在编辑中补全。

每行提供查看、编辑和删除。编辑项目名称、公司和描述时保留已生成成果；修改技术产品或知识产权类型后须重新选择问题，开始对应的新生成流程。删除需要确认，取消删除会保留项目；删除正在生成的项目会终止该项目的客户端任务，不影响其他项目。

生成进度直接显示在列表。点击项目名称，在项目管理弹窗中处理产品矛盾、确认彩色预览、重画、重试、查看材料和导出 Word。关闭详情弹窗会继续生成。旧 `#utility` 地址转入项目管理弹窗，独立的实用新型创作页面不再作为入口。

实际生成完成的发明或实用新型专利显示三个可点击按钮：

- 未提交申报（默认）
- 申报中
- 申报完毕

用户可以任意切换，当前状态通过 `aria-pressed` 和颜色标记，随项目持久保存，并支持筛选。这是人工登记的业务状态；普通草稿或仅手动标记“已整理”的项目不显示申报按钮。新一版技术方案重新生成后，申报状态重新从未提交开始。

项目 JSON 使用 `companyId`、`baseProductName`、`filingStatus` 保存企业关联、基础产品名和申报状态，旧项目兼容缺省字段。企业目录单独持久保存：MySQL 使用 `company_directories` 表与 `/api/storage/companies` 接口，带版本冲突校验，按账号和工作空间隔离；IndexedDB 使用对应空间的目录键。首次访问自动初始化目录，空目录保留初始化标记，避免删除后被历史资料再次填回。数据库启动时通过现有 schema 机制创建新表。

任务在当前应用页面存续期间运行，刷新后保留已有成果并把未完成请求标为中断，用户可在项目详情中继续。生成在需要用户处理矛盾或确认彩色预览时等待明确操作。
