## 使用入口及流程

发明专利与实用新型使用 `ProductWorkflowWorkspace`：确认名称与资料 → 产品逻辑校验与去矛盾 → 产品简介与四张彩色预览 → 确认后生成 FreeCAD 附图、文案与 Word。完整操作及测试见 [产品工作区说明](product-workflow.md)。

旧结构工作区已于 2026-10-12 删除。下面的几何格式、附图和材料说明用于理解历史项目，以及仍保留的结构 API 与旧项目导出；不代表当前页面提供旧工作区操作。

## AI 几何数据契约

以下是结构模型服务返回的几何格式，不是工作区中的用户输入界面。长度单位为 mm，旋转单位为度：

```text
名称 | 形状 | 位置 x,y,z | 尺寸 | 旋转 x,y,z（可省略）
```

- 长方体尺寸：长、宽、高；位置为旋转前左下后角。
- 圆柱体尺寸：半径、长度；圆管尺寸：外半径、长度、内半径。
- 圆柱及圆管默认沿 Z 轴，位置为底面圆心。
- X 向右、Y 向后、Z 向上；绕部件位置依次绕 X、Y、Z 旋转，再平移到装配位置。
- 1–30 部件；名称不重复且 1–40 字，位置 ±10000，尺寸 0.1–10000，角度 ±360；圆管内半径小于外半径。

服务端会校验并编译 AI 返回的几何数据；格式不合格时自动重试，连续失败只提供重新生成，不要求用户手动填写。

## 模型与保存

- 已删除固定 22 部件参考装配生成器；模型由当前项目的部件数据构建。
- 三视图共享同一三维模型和编号：整体为轴测，侧面为沿 +X 观察的正投影，局部为整体图 A 区的同方向等比例裁切。
- 标号始终为一条细实线加纯数字，无圈框、箭头或端点圆点；A 框是取图区域，不是部件标号。
- 生成版式参考用户提供的历史附图：A4 纵向页面、顶部“说明书附图”、图下方“图1 / 图2 / 图3”、黑白线稿、适当留白。参考资料只提供视觉规范，不上传给第三方 AI，也不复制其中吊椅、茶几、躺床或风机的产品结构。
- 每次生成都会基于当前专利名称对应的产品方案重新建立部件几何和编号；参考图不会成为固定产品模板。
- 名称、技术领域、结构组成、工作原理、几何内容共同记录在生成来源中。修改任何一项都会隐藏旧图并禁用图片导出，材料不再引用过期编号，重新核对生成后恢复。
- 几何、编号、来源及局部目标保存到既有 `zhichuang-projects-v1`；旧版迁移保留文字，清除参考模型展示。
- 新建及切换项目不会沿用上一个项目的图或命名表单。

## AI 能力与边界

现已接入公开专利网页检索及真实模型，可仅凭已确认名称自动提出具体产品、结构和工作原理。最多保留 5 篇带检索工具来源及引用的公开专利，记录实际检索词、日期及打开操作记录。检索不足或失败不自动回退模型记忆。模型推定的示意尺寸会列为待验证假设。结构服务连续两次返回无效草案时只报告自动生成失败，不要求用户手动补齐。检索是有限范围参考，不保证穷尽、真实性或新颖性；AI 提出内容不视为已核实技术事实。旧的概念绘图 API 仅作服务端兼容测试使用，不是当前工作区入口。完整配置与服务安全说明见 `docs/ai-drawing.md`。

支持统一参数化协议中的长方体、圆柱体、圆管、外齿直齿轮、内齿圈、圆锥体、球体、椭球体、棱柱、环面、螺旋弹簧和螺纹圆柱透明线框；不支持任意自由曲面、叶片复杂曲面、非参数轮廓或遮挡消隐。格式检查不能证明机械可行性，结构说明与图形的一致性仍需人工核对。复杂结构应转专业 CAD，材料仍为整理初稿。
