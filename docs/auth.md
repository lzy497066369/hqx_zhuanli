# 登录和注册

登录、注册、退出与会话恢复已经接入 MySQL。未登录时只显示账号页面，服务端同时拒绝项目、资料库和 AI 业务接口访问；仅账号接口和存储健康检查可匿名访问。普通用户注册或登录成功后直接进入项目管理的企业列表（`#projects`）。已有登录会话访问根地址时同样进入项目管理；带明确页面地址的刷新保留当前页面。管理员仍默认进入管理控制台。

账号为 3–32 位字母、数字或下划线，不区分大小写，数据库有唯一索引。昵称可选，默认使用账号；密码为 8–128 位。重复账号、错误密码、两次密码不一致、服务故障均显示具体提示。管理员可以在管理控制台重置用户密码。

## 新增表和字段

| 表 | 字段 | 用途 |
| --- | --- | --- |
| `users` | `id`, `username`, `display_name`, `password_hash`, **`role`**, `created_at`, `updated_at`, `last_login_at` | 用户账号、昵称、密码哈希、预留权限字段与时间 |
| `user_sessions` | `token_hash`, `user_id`, `expires_at`, `created_at` | 登录会话摘要、所属用户、过期与创建时间 |

`users.role` 为 `VARCHAR(32) NOT NULL DEFAULT 'user'`。注册接口固定写入 `user`（普通用户），忽略客户端传入的 role。第 4 版迁移创建唯一的默认管理员 `admin`，初始密码 `admin123`，密码仍以 scrypt 哈希保存。迁移仅执行一次，后续启动不会重置已修改的管理员密码；历史同名账号由此次迁移归为默认管理员并撤销其旧会话。

管理员登录后进入管理控制台，也可从创作工作台侧栏进入 `#admin`。控制台支持新增用户、编辑账号/昵称/角色、重置密码、禁用/启用、删除用户，以及按用户查看工作空间和完整项目内容、导出项目 JSON。修改账号会撤销其所有旧会话；禁用账号无法登录或使用已有会话。默认管理员不能改账号名、删除、禁用或降为普通用户，当前登录账号也不能删除、禁用或自行降权。删除用户需要输入账号确认，会级联删除其工作空间、项目、草稿及资料，AI 审计记录保留。

`/api/admin/*` 由服务端重新验证会话及管理员角色，无需工作空间请求头。普通用户返回 403，未登录返回 401；即使测试模式关闭全局登录，管理接口也禁止访问。管理 API 包括 `GET/POST /users`、`PATCH/DELETE /users/:id`、`GET /workspaces?userId=...`、`GET /projects`、`GET /project?workspaceId=...&id=...`、`GET /ai-requests`、`GET /ai-requests/:id`（均以 `/api/admin` 为前缀）。

AI 请求日志保存于 MySQL `ai_request_logs`，逐次记录文本、检索、图片和视觉模型调用，重试独立记录并以关联请求 ID 串联。日志含用户、空间、业务接口、模型、服务地址、请求/完成时间、HTTP 状态、请求及实际响应是否流式、首字节/首内容片段/输出/总耗时、输入/输出/总 Token 与供应商原始用量明细、请求参数、响应内容、结束原因、错误及内容校验错误。列表支持搜索、时间/状态/流式筛选、分页、统计与自动刷新，详情支持导出 JSON。调用成功表示供应商响应完整，确定性内容校验失败也会标为失败；不代表整个专利流程最终成功。

日志仅记录功能上线后的调用，不能补回历史请求。非流式响应无法观测首字及输出区间，显示「—」；未报告 Token 显示「—」，统计同时标注未报告次数。日志隐藏密钥、密码和认证头，图片二进制仅保留类型/大小信息或长度说明；文本与协议响应最多保存 16 MB，超过时明确标注截断。日志读取与写入均不调用真实模型。

密码使用随机盐和 Node 的 scrypt 存储，数据库没有明文密码。登录会话使用随机 32 字节令牌，仅 SHA-256 摘要保存在数据库；浏览器使用 `HttpOnly`、`SameSite=Lax` Cookie，HTTPS 时附加 `Secure`。会话有效期 7 天，每个用户保留最多 10 个有效会话；退出立即删除当前会话并清除 Cookie。账号接口具有同源校验、请求体限制和按来源 / 账号的尝试次数限制。

`server/mysql/auth.sql` 是数据库结构来源，由现有初始化程序自动执行并记录第 2 版迁移：

```sh
npm run db:migrate
```

接口：`POST /api/auth/register`、`POST /api/auth/login`、`POST /api/auth/logout`、`GET /api/auth/me`。登录与注册输入为 `username`、`password`，注册可带 `displayName`。接口只返回用户公开字段，不返回密码哈希或会话令牌。

## 部署

生产默认启用登录；Compose 明确设置 `AUTH_REQUIRED=true`。局域网 Caddy 网关转发到前端 Nginx，原来的共享 Basic Auth 登录框由应用内登录注册取代，访问地址不变。历史回归测试显式使用 `AUTH_REQUIRED=false`，仅用于隔离测试环境。

账号拥有独立工作空间，一个账号可新建多个空间，项目、草稿和资料按空间隔离。管理员只通过管理接口跨用户读取项目；原有创作及存储接口仍校验空间所属用户。空间管理和新增字段见 [独立工作空间](workspaces.md)。数据库故障或会话过期时保存失败会提示未保存状态，先备份当前修改再重新登录。

## 验证

```sh
npm run test:auth
npm run test:admin
npm run lint
npm run build
```

真实 MySQL 测试覆盖角色参数不能提权、密码与会话摘要、重复账号、错误密码、未登录拦截、注销、过期与伪造会话、服务重启后恢复、跨站请求和登录限流。浏览器测试覆盖注册自动登录、刷新、用户信息、退出和重新登录、手机布局、无障碍检查及服务故障重试。测试账号会自动删除。

`test:admin` 使用独立数据库 `zhichuang_admin_test`（可用 `ADMIN_TEST_DATABASE` 指定相同前缀的其他测试库），需提前创建该库并给应用 MySQL 账号授权。该测试不会迁移正在运行的应用数据库，也不请求真实模型或重新部署。
