# 知创工坊设计系统

基于 ui-ux-pro-max 检索结果，按用户指定的白色简洁风格调整。无需外部字体或图片请求。

- 桌面工作台：224px 侧栏 + 顶栏 + 主内容。1024px 起四类创作入口同排；平板/手机两列，避免横向溢出。
- 背景 #F8FAF9，卡片 #FFFFFF，主色 #267357，正文 #252C29。
- 四类方向：绿色（发明）、蓝色（实用新型）、紫色（外观）、暖棕色（软著）。
- 中文系统无衬线字体、清晰标题层级、细分隔线、轻量圆角；同系列 Lucide 图标与原创 SVG 线稿。
- 控件可见焦点；原生 dialog 支持焦点锁定与 Escape；动效尊重 reduced-motion。
- 前端边界：无 AI / 账户 / 云端申报接口。项目 localStorage 保存，资料库仅保留当前会话元信息。
- 示例项目明确标注；导出为待填写 TXT 模板，不宣称生成正式申请文件。
